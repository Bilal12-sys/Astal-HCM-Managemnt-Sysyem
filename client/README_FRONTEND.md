# Astral HCM Lite Frontend

Run the client with `npm run dev` inside `client`.

Copy `.env.example` to `.env` and set `VITE_API_URL` to the backend API base URL.

The initial frontend foundation uses `src/assets/Astral_Technologies.jpg` directly on the landing page and includes a matching SVG mark for UI use. Theme tokens are extracted from the logo: deep/royal/sky blue ribbons and a cyan star.

Contract gap: the backend does not include `API_CONTRACT.md` or routes for attendance, leave, payroll, settings, organization, employee, dashboard, announcements, and notifications. These will not be invented in the client.
