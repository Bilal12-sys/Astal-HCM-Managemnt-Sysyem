# Frontend Style Guide

1. Use React function components: `function LandingPage() {}`.
2. Use single quotes and semicolons.
3. Use two-space indentation for readable multi-line code.
4. Add one short plain-English comment above every component and function.
5. Use PascalCase components and camelCase variables.
6. Keep API requests in `src/api/`.
7. Keep protected route rules in `src/auth/`.
8. Keep shared state in `src/context/`.
9. Use the Astral CSS variables instead of hard-coded page colors.
10. Reuse shared components such as `Button` and `EmptyState`.
11. Do not create dummy business records or dashboard numbers.
12. Use semantic labels and keyboard focus outlines.
13. Keep components simple and near 200 lines where practical.
14. Use clear names such as `temporaryPassword`, not abbreviations.
15. Preserve Daylight and Astral Night readability.
16. Keep loading, empty, error, and success states explicit.
17. Use the logo image without stretching or recoloring it.
18. Do not put server endpoint strings inside page components.
